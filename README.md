# Kuzey Durden

I build onchain applications, analytics tools, and automation.

My work combines Solidity contracts, TypeScript interfaces, and Python data pipelines, with an emphasis on making complex onchain activity easier to understand.

### Selected projects

| Project | What it does |
| --- | --- |
| [EXPOSURE](https://github.com/0xkuzeydurden/exposure) · [Live demo](https://exposure.clinic) | Token analytics presented as an onchain radiology report, with explainable findings and recorded scan replays. |
| [Base GMGN](https://github.com/0xkuzeydurden/base-gmgn) | A Base application for wallet-connected GM/GN interactions and ERC-20 deployment, built with Next.js and Solidity. |
| [Arc Playground](https://github.com/0xkuzeydurden/arc-playground) | A testnet playground for wallet interactions, token deployment, and USDC bridging with Circle Bridge Kit. |
